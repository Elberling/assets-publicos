Uso pessoal

Clark

Ferramenta pessoal de publicação usada por Elberling Oliveira de Castro para enviar os próprios vídeos e imagens às suas próprias contas.

O que é

Clark é um conjunto de scripts que roda no computador pessoal do autor. Ele pega arquivos de mídia que o próprio autor produziu e os publica nas contas do próprio autor, usando as APIs oficiais de cada plataforma.

Para que serve

  • Enviar vídeos ao canal do YouTube do autor
  • Publicar imagens no perfil de Instagram do autor
  • Ler as métricas públicas dessas mesmas contas

Quem usa

Somente o autor. Não há cadastro, não há login de terceiros, não há usuários além do dono das contas. A ferramenta não é oferecida, vendida nem distribuída a outras pessoas.
